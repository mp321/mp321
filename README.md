
Quick summary:
GitHub page for a few public-facing projects. Owner currently based in San Francisco. 

## Projects

- **[LiveEarth](https://mp-live-earth.vercel.app/)** - real-time 3D globe: satellite imagery with live flights, weather, seismic, and ocean layers
  (React, MapLibre GL, deck.gl, Vercel serverless).
- **[sf-data-warehouse](https://github.com/mp321/sf-data-warehouse)** - analytics warehouse over seven San Francisco open datasets: a Parquet raw zone, precomputed H3 geography, and dbt marts with 148 tests running in CI (Python, dbt, DuckDB, BigQuery, GitHub Actions).
- **[DataBrief](https://mp-ml-toolkit.vercel.app/)** - a browser-based data profiler. Open a CSV or Excel file and you get types, missing values, distributions and quality flags, then copy the whole profile as ready-made context for an AI assistant. It's Streamlit compiled to WebAssembly (stlite on Pyodide), so everything runs inside the tab and your file never leaves your computer. Alongside it: ML Coach, plain-English lessons that end in a guided walkthrough training a real model on your own data, and an experimental ML Workbench for exploration and model training.
- **[Revenue Integrity SourceWatch](https://mp321.github.io/RevInt-SourceWatch)** - automated check of official Medi-Cal and federal billing sources that flags what changed and points a human to re-verify (Python, GitHub Actions).
- **[Practical AI](https://mp-practical-ai.vercel.app/)** - quick lessons for anyone to improve high level prompting skills with AI.
- **[Arcadia](https://mp-arcadia.vercel.app/)** - a mini browser game built in plain HTML, a quick experiment.
